FAQ

Frequently asked questions

What is ILMA.AI?

An independent, single-operator pipeline that detects trending topics, turns a selected one into a short vertical video with a script and voice-over, and publishes it to connected social accounts. See How it works for the full stage-by-stage breakdown.

Is ILMA.AI a company, or something I can sign up for?

No. It's a solo project with one operator and one connected account per platform — not a multi-tenant product, and not something the public can create an account on. There is no signup flow.

Does it post to TikTok and Instagram without any human review?

Publishing only happens on platforms the operator has explicitly connected and enabled. When enabled, the pipeline publishes automatically on a schedule — there is no manual approval step per video — but every step uses each platform's official publishing API, never scraping or unofficial automation.

What TikTok and Instagram permissions does ILMA.AI use, and why?

On TikTok: TikTok's Content Posting API with the video.publish scope, obtained through TikTok's own OAuth consent screen. On Instagram: the Instagram API with Instagram Login (Meta's Graph API), including the content publishing permission, obtained through Instagram's own OAuth consent screen. Neither platform's password is ever seen or stored by ILMA.AI — only the access tokens each platform issues after the operator approves the connection.

What happens to the data ILMA.AI touches?

The only personal data involved is the connected account's own OAuth tokens and basic public identifiers, stored locally and never sold or shared. Full detail is in the Privacy Policy.

Where do the videos' topics and scripts come from?

Topics come from public sources — Hacker News, public Reddit listings, and RSS feeds. Scripts are generated fresh for each topic (via a language model or a template fallback), not copied from the source article. See How it works.
