The pipeline

Six stages, one automated loop.

ILMA.AI runs the same six-stage cycle on a schedule. Each stage is a small, independent module — if a paid or heavier tool isn't available (a local language model, a text-to-speech engine, a video renderer), that stage falls back to a lighter, free alternative rather than stopping the pipeline.

  1. 01

    Collect

    Pulls currently-trending topics from public, open sources — Hacker News, public Reddit listings, and RSS feeds. No login-walled scraping and no private data of any kind is touched at this stage.

  2. 02

    Score

    Ranks the collected topics with a simple viral-potential score — a mix of source popularity, freshness, and how well the source itself has historically performed — and keeps only the top few.

  3. 03

    Script

    Turns the selected topic into a short hook / body / call-to-action script — via a locally-run language model when one is available, or a template-based writer when it isn't. Every script is generated fresh for that topic, not copied from a source article.

  4. 04

    Voice

    Converts the script into a voice-over using free neural text-to-speech voices, so every video has narration without needing a human recording session.

  5. 05

    Video

    Assembles a vertical (9:16) video with burned-in captions from the voice-over and any supporting visuals, sized and encoded for short-form vertical feeds.

  6. 06

    Publish

    Sends the finished video to whichever platforms are connected and explicitly enabled, exclusively through each platform's official publishing API — see below. If no platform is enabled, the video is simply queued and never sent anywhere.

Publishing, platform by platform

TikTok

Videos are published using TikTok's official Content Posting API with the Direct Post product. The connected account authorizes ILMA.AI once, through TikTok's own OAuth consent screen (PKCE flow) — ILMA.AI never sees or stores the account's TikTok password. Every publish call goes through TikTok's API using the video.publish scope; nothing is scraped and no part of the TikTok app or website is automated directly.

Instagram

Videos are published as Reels using Meta's official Instagram API with Instagram Login (no Facebook Page required). The flow is: create a media container that points at the rendered video, poll until Instagram finishes processing it, then publish the container. Authorization again happens through Instagram's own OAuth consent screen — ILMA.AI never sees or stores the account's Instagram password.

What's off by default

Every platform integration ships disabled. An operator has to explicitly connect an account and flip a setting before ILMA.AI will publish anything on their behalf — the pipeline runs its collect / score / script / voice / video stages regardless, but stops short of publishing until that switch is on.
