Privacy Policy

Effective September 3, 2026 · v1.1

ILMA.AI is a single-operator automation project, not a consumer app with a user base. It does not collect personal data from the public. This policy explains the only personal data the system touches: the TikTok and/or Instagram account credentials of the account(s) it publishes to.

01What is stored

DataWhyWhere
TikTok OAuth access & refresh tokensRequired by TikTok's Content Posting API to publish videos on the operator's behalfLocal database, not shared
TikTok open_id and public usernameIdentify which connected account a token belongs toLocal database
Instagram OAuth access & refresh tokensRequired by the Instagram API with Instagram Login to publish Reels on the operator's behalfLocal database, not shared
Instagram user idIdentify which connected account a token belongs toLocal database
Video performance stats (views, likes, followers)Shown on the operator's private dashboardLocal database

No visitor analytics, cookies, or tracking pixels are used on the ILMA.AI dashboard. No data about people who view the published TikTok or Instagram content is collected by ILMA.AI beyond the aggregate counts each platform's own API reports.

02How OAuth tokens are used

When the operator connects a TikTok account, TikTok issues an access token and a refresh token scoped to user.info.basic and video.publish. When the operator connects an Instagram account, Instagram issues an access token scoped to basic account access and content publishing. In both cases, tokens are used only to call that platform's official API to check posting eligibility, upload a video, and check publish status. Tokens are never used to read private data, message other users, or take any action beyond posting videos.

03Storage & security

Tokens are stored in a local database on the operator's own machine, never committed to source control, and never transmitted anywhere except to TikTok's or Instagram's API over HTTPS. The client secrets used to obtain tokens are kept in a local, git-ignored configuration file.

04Sharing

No data is sold, rented, or shared with third parties. Stats shown on the dashboard are visible only to the operator.

05Retention & deletion

Tokens are kept only as long as the account stays connected. Revoking ILMA.AI's access from TikTok's or Instagram's own app-permissions settings, or deleting the local database, removes them immediately. Contact the address below to request deletion of any stored data.
