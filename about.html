About

One person, one computer, zero budget.

ILMA.AI is an independent project, built and operated by a single person. There is no company behind it, no team, and no outside funding — just one computer running a pipeline that was built in public, stage by stage.

The premise

Short-form video is time-consuming to produce well: finding a topic worth covering, writing something worth watching, recording narration, editing, and publishing — all before the topic stops trending. ILMA.AI is an experiment in whether that entire loop can be automated end-to-end, honestly and within every platform's own rules, using free and open tools rather than a paid content-operations stack.

How it's built

The backend is a small Python service (FastAPI) that runs the collect → score → script → voice → video → publish pipeline described on the How it works page, plus a private dashboard for the operator to watch it run, review what got published, and see errors when a stage fails. Every piece is either open-source or a platform's own official API — see that page for the specifics.

The rule that doesn't bend

ILMA.AI only ever talks to TikTok and Instagram through their official, documented publishing APIs, with an account the operator explicitly connects and authorizes through that platform's own OAuth screen. It does not scrape either platform, does not automate logins, and does not publish anything until the operator has switched that platform on. The Terms of Service and Privacy Policy pages go into the specifics of what that means for the connected account.

Where it's headed

The project is still early and still run by hand day to day. Near-term work is about reliability — keeping the pipeline running unattended for longer stretches and adding more trend sources — before any bigger changes are considered. There's no roadmap promise beyond that; this is a solo project, and it moves at a solo project's pace.
